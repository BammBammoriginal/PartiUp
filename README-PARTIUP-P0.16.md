# PartiUp P0.16

P0.16 vertieft Orte und Themen als zwei zentrale Navigations- und Discovery-Achsen von PartiUp.

## Testen
1. `setup.bat` ausführen.
2. `start-local.bat` starten.
3. Orte öffnen und zwischen Ortskontext, Themenchips und „Lokal entdecken“ wechseln.
4. Themen öffnen und Ortsbezüge sowie verwandte Themen prüfen.
5. Unter „Entdecken“ die Reiter Lokal, Communities und Themen prüfen.

Alle Übersichten basieren auf bestehenden Verknüpfungen; es gibt kein algorithmisches Ranking.
