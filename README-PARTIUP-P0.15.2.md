# PartiUp P0.15.2 – Media Presentation Fix

Diese Bugfix-Version verbessert ausschließlich die Darstellung von Beitragsbildern.

Kleine Bilder behalten ihre natürliche Größe und werden nicht mehr auf Kartenbreite aufgeblasen. Große Bilder bleiben responsiv und werden in der Höhe begrenzt. Die gleiche Regel gilt für den zentralen Feed und den Feed innerhalb eines Space.

Start unter Windows PowerShell:

```powershell
.\setup.bat
.\start-local.bat
```

LAN:

```powershell
.\start-network.bat
```
