# PartiUp P0.12.8

P0.12.8 erweitert **Entdecken** um einen kuratierten **Fediverse**-Tab. Der Bereich ist bewusst kein Portal oder Live-Verzeichnis. Er erklaert das Fediverse in einfacher Sprache und verlinkt auf eine kleine kuratierte Auswahl offener Anwendungen.

## Start unter Windows

```powershell
.\setup.bat
.\start-local.bat
```

Im LAN:

```powershell
.\start-network.bat
```
