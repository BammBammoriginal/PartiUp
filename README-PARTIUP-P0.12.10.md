# PartiUp P0.12.10

UX-/Navigations-Update für **Entdecken**. „Für dich“ dient als verständliche Landingpage, während Lokal, Communities, Themen und Fediverse weiterhin eigenständige Entdecken-Kontexte bleiben.

Die Landingpage verwendet nur bereits vorhandene Beziehungen und sichtbare Objekte. Es gibt kein Empfehlungsranking und keine Tracking-/Engagementlogik.

## Start unter Windows PowerShell
```powershell
.\setup.bat
.\start-local.bat
```
LAN:
```powershell
.\start-network.bat
```
