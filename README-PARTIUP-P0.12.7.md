# PartiUp P0.12.7

Diese Version bündelt Profil- und Sichtbarkeitseinstellungen in einem Privacy Control Center. Privacy-by-default bleibt restriktiv; `network` bedeutet akzeptierte Freundschaft, `members` bedeutet angemeldetes PartiUp-Mitglied. Profileinträge können niemals die Zugriffsrechte ihres Ursprungsobjekts erweitern.
