# PartiUp P0.12

Event-Teilnahme wird zu einem vollständigen PartiUp-Prozess: Teilnehmen, Anfragen, Freigabe, Absagen, Warteliste und föderierte Join/Leave/Accept/Reject-Aktivitäten. Die UI bleibt PartiUp-nativ; personenbezogene Teilnehmerlisten werden nicht ins Fediverse veröffentlicht.

## Windows PowerShell
```powershell
.\setup.bat
.\start-local.bat
```
LAN:
```powershell
.\start-network.bat
```
