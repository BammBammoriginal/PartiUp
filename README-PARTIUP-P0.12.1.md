# PartiUp P0.12.1

Diese Version erweitert den persönlichen Bereich **Mein Netzwerk**.

Die drei persönlichen Beziehungsebenen sind nun klar getrennt:
- **Freunde** – bestätigte persönliche Beziehungen inklusive offener Anfragen
- **Mitgliedschaften** – Spaces, in denen der Nutzer Mitglied ist
- **Gefolgte Bereiche** – Communities, Orte, Themen und Personen/Objekte, denen gefolgt wird

Die Friendship-Funktion erweitert das bestehende Relationship-Modell, ohne Follow-, Membership-, Community-, Rollen- oder Federation-Prozesse umzubauen. Sie wird derzeit bewusst lokal in PartiUp geführt und nicht als ActivityPub-Freundschaft behauptet.

Start unter Windows PowerShell:
```powershell
.\setup.bat
.\start-local.bat
```

LAN:
```powershell
.\start-network.bat
```
