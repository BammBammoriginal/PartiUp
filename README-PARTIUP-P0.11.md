# PartiUp P0.11

P0.11 macht die vorhandene Federation in der normalen PartiUp-UX nutzbar. Nutzer sehen keinen separaten „Fediverse-Bereich“ mehr: lokale und externe Beiträge erscheinen in derselben chronologischen Liste. Herkunft und Vertrauensstatus bleiben sichtbar, ohne die Oberfläche zu dominieren.

## UX-Grundsätze

- Ein Produkt statt getrennter lokaler/remote Oberflächen.
- Herkunft bleibt transparent: PartiUp oder Fediverse + Quellserver.
- Trust-/Governance-Einstufung wird als kompakter Status gezeigt.
- Keine algorithmische Ranking-Logik; Reihenfolge bleibt chronologisch.
- Filter erlauben jederzeit Alle / PartiUp / Fediverse.
- Lokale Funktionen wie Kommentare und Moderation bleiben erhalten.
