# PartiUp P0.12.6

Persönliche Aktivität ist kein Social-Media-Feed, sondern eine bewusst kuratierte Liste bereits existierender PartiUp-Objekte.

## Testen
1. Objekt öffnen (Community, Event, Projekt, Thema oder Beteiligung).
2. „Auf Profil hervorheben“ wählen, optionalen Begleittext und Sichtbarkeit setzen.
3. Eigenes Profil → „Persönliche Aktivität“ öffnen.
4. Originalobjekt über den Connection-Chip öffnen.
5. Sichtbarkeit ändern, Begleittext bearbeiten und Eintrag entfernen.
6. Mit einem zweiten Nutzer prüfen, dass private bzw. nicht mehr zugängliche Originalobjekte nicht offengelegt werden.
