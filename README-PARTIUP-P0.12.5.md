# PartiUp P0.12.5

Persönliche Profile bilden eine datenschutzorientierte Netzwerkidentität ab. Sie zeigen nur freigegebene Beziehungen und Aktivitäten aus bereits vorhandenen Core-Daten.

## Start unter Windows

```powershell
.\setup.bat
.\start-local.bat
```

LAN:

```powershell
.\start-network.bat
```
