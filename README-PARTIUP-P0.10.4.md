# PartiUp P0.10.4 – konsistente Space-UX & Aufgaben-Selbstzuweisung

P0.10.4 vereinheitlicht die Informationsarchitektur der aktuell vorhandenen Space-Typen. Echte Funktionen bleiben in der Funktionsnavigation; Transparenz/Herkunft liegt unter `ⓘ Info`, Administration unter `⚙ Einstellungen`.

Das Aufgabenmodul erhält eine getrennte Berechtigung für freiwillige Selbstzuweisung (`task.self_assign`). Die Rechte für Fremdzuweisung (`task.assign`) bleiben davon getrennt.

## Windows
```powershell
.\setup.bat
.\start-local.bat
```

LAN:
```powershell
.\start-network.bat
```
