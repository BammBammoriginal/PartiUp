# PartiUp P0.12.4

P0.12.4 ist ein Konsistenz- und Regression-Release. Es zieht die persönlichen Netzwerk-, Follow- und Connection-Muster aus P0.12.1–P0.12.3 über relevante Listen, Karten, Profile, Suche/Entdecken und vernetzte Ansichten hinweg durch.

Start unter Windows PowerShell:

```powershell
.\setup.bat
.\start-local.bat
```

LAN:

```powershell
.\start-network.bat
```

Neue zusätzliche Prüfung:

```powershell
npm run preflight:cross-space-consistency
```
